Diretório independente de grupos, canais e comunidades do WhatsApp, com moderação, OTP, catálogo e privacidade.

== Installation ==
Envie o ZIP, ative o plugin e configure em Portal Grupos > Configurações. Consulte README.md para o mapa completo de shortcodes e operação.
