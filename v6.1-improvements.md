## 🚀 NOVOS ITENS IDENTIFICADOS PARA MELHORIA

### 1. **PRELOAD DE IMAGENS LCP CRÍTICAS** ⭐ PRIORIDADE MÁXIMA
**Problema**: A primeira imagem (hero/coverage) não está com preload
**Solução**: Detectar primeira imagem e adicionar `<link rel="preload" as="image">`

```php
// Detecta URL da primeira imagem grande na homepage
// Adiciona preload com fetchpriority="high"
```

### 2. **REMOVE GOOGLE FONTS BLOCKING** ⭐
**Problema**: Google Fonts ainda pode bloquear renderização
**Solução**: 
- Trocar para `&display=swap` na URL
- Ou usar `font-display: optional` para fonts não-críticas
- Considerar self-host com preload

### 3. **REDUZIR TEMPO DE EXECUÇÃO DO SERVIDOR (TTFB)**
**Problema**: PHP execution time pode estar alto
**Solução**:
- Object Cache (Redis/Memcached)
- Database query optimization
- Preload de opções do WP

### 4. **LAZY LOAD EM BACKGROUND-IMAGES VIA CSS** ⭐⭐
**Problema**: Background images em seções abaixo da dobra
**Solução**:
```css
.bt_bb_section:nth-of-type(n+3) {
    background-image: none !important;
}
/* Carrega via JS IntersectionObserver */
```

### 5. **REMOVE UNUSED CSS DO ELEMENTOR/WPBakery** ⭐⭐⭐
**Problema**: CSS de builders não usados na página
**Solução**:
- Detectar quais shortcodes estão na página
- Remover CSS de elementos não presentes

### 6. **OTIMIZAR QUERY DO PRECONNECT** ⚠️
**Problema**: Query no preconnect pode ser lenta
```php
$wpdb->get_col("SELECT guid FROM...") // 50 imagens = query pesada
```
**Solução**:
- Cache transiente (1 hora)
- Ou lista hardcoded dos domínios principais

### 7. **ADICIONAR RESOURCE HINTS DINÂMICOS**
**Problema**: Só preconnect, falta prefetch/preload
**Solução**:
- `prefetch` para páginas prováveis (contato, sobre)
- `preload` para fonts e imagens críticas

### 8. **INLINE CRITICAL IMAGES (LCP)** ⭐⭐
**Problema**: Imagem hero precisa carregar instantaneamente
**Solução**:
- Base64 imagem hero se < 14KB
- Ou preload agressivo

### 9. **REMOVE WP-BLOCK CSS SE NÃO USAR GUTENBERG** ⭐
**Problema**: wp-block-library.css carregando sem necessidade
**Solução**:
```php
wp_dequeue_style('wp-block-library');
```

### 10. **OTIMIZAR CARREGAMENTO DE ÍCONES/SVG**
**Problema**: Icon fonts ou SVGs inline grandes
**Solução**:
- Inline apenas ícones acima da dobra
- Sprite SVG para ícones repetidos

### 11. **CONTENT-VISIBILITY AUTO EM LISTAS** ⭐
**Problema**: Listas longas de posts/projetos
**Solução**:
```css
.post-list > .post-item:nth-of-type(n+4) {
    content-visibility: auto;
    contain-intrinsic-size: 0 400px;
}
```

### 12. **LAZY HYDRATION DE WIDGETS/BLOCKS** ⭐⭐
**Problema**: Widgets complexos hidratam cedo demais
**Solução**:
- IntersectionObserver para hidratar widgets visíveis
- Adiar widgets de rodapé

### 13. **REMOVE EMBEDS DESNECESSÁRIOS**
**Problema**: WordPress tenta detectar embeds em todo texto
**Solução**:
```php
remove_filter('the_content', 'wp_oembed_add_discovery_links');
```

### 14. **OTIMIZAR HEADER FOOTER SEPARADOS**
**Problema**: Header/footer carregam juntos com conteúdo
**Solução**:
- Separar CSS do header (crítico)
- Footer CSS async

### 15. **ADD FETCHPRIORITY EM IMAGENS CRÍTICAS** ⭐⭐⭐
**Problema**: Navegador não sabe prioridade das imagens
**Solução**:
```html
<img src="hero.jpg" fetchpriority="high" loading="eager">
```

### 16. **PREVENT LAZY LOAD EM LCP IMAGE** ⭐⭐⭐
**Problema**: Primeira imagem com loading="lazy" atrasa LCP
**Solução**:
- Primeira imagem: loading="eager" + fetchpriority="high"
- Demais: loading="lazy"

### 17. **MINIFY INLINE CSS/JS** ⭐
**Problema**: CSS/JS inline sem minificação
**Solução**:
- Remover comentários
- Remover whitespace desnecessário

### 18. **LAZY LOAD VIDEOS/YOUTUBE** ⭐⭐⭐
**Problema**: Embeds de YouTube carregam iframe pesado
**Solução**:
- Placeholder estático primeiro
- Carrega iframe on click/intersection

### 19. **REMOVE DUPLICATE FONTS**
**Problema**: Mesma fonte carregada múltiplas vezes
**Solução**:
- Deduplicar URLs de fonts
- Unificar weights

### 20. **OPTIMIZE THIRD-PARTY SCRIPTS** ⭐⭐
**Problema**: Analytics, Facebook Pixel, etc. bloqueiam
**Solução**:
- Carregar após interação do usuário
- Usar web worker se possível

### 21. **ADD SIZES ATTRIBUTE EM IMAGENS RESPONSIVE** ⭐
**Problema**: Imagens sem sizes atributo
**Solução**:
```html
<img srcset="..." sizes="(max-width: 768px) 100vw, 1280px">
```

### 22. **LAZY LOAD GRAVATAR/AVATARS**
**Problema**: Múltiplos gravatars em comentários
**Solução**:
```php
add_filter('get_avatar', 'lazy_load_avatar');
```

### 23. **REMOVE JQUERY MIGRATE** ⭐
**Problema**: jquery-migrate.js carregando sem necessidade
**Solução**:
```php
wp_deregister_script('jquery-migrate');
```

### 24. **ASYNC ANALYTICS** ⭐
**Problema**: GA4/GTM bloqueando renderização
**Solução**:
- Carregar analytics após window.load
- Usar requestIdleCallback

### 25. **OPTIMIZE WOOCOMMERCE ASSETS** (se aplicável)
**Problema**: WooCommerce carrega CSS/JS em todas páginas
**Solução**:
```php
// Só carrega em páginas de produto/carrinho
```
